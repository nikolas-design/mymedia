# Εργαλεία (modules)

Κάθε εργαλείο της πλατφόρμας (QR Boss, Review Booster, Ταμείο κ.λπ.) ζει στον δικό του φάκελο:

```
modules/<slug>/
  index.php            ← σημείο εισόδου (υποχρεωτικό)
  public.php           ← δημόσιες σελίδες χωρίς login (προαιρετικό)
  migrations/001_*.sql ← δικοί του πίνακες (προαιρετικό)
  views/               ← δικές του σελίδες (προαιρετικό)
  assets/              ← css/js/εικόνες, σερβίρονται κανονικά
```

Το `<slug>` είναι το ίδιο με το `tools.slug` στη βάση: `qr-boss`, `review-booster`, `orderflow`, `tameio`, `shifts`, `appointments`, `websites`, `ai-content`, `restaurant-ordering`, `hotel-booking`, `lessons`.

## Πώς φορτώνεται

Η διεύθυνση `/t/<slug>/<υπόλοιπο>` περνά από την πύλη, η οποία ελέγχει:

1. ότι ο χρήστης είναι συνδεδεμένος,
2. ότι ανήκει σε επιχείρηση,
3. ότι η επιχείρηση έχει **ενεργή συνδρομή** στο εργαλείο,
4. ότι κάθε POST έχει έγκυρο CSRF token (βάλε `<?= csrf_field() ?>` σε κάθε φόρμα).

Μετά φορτώνει το `modules/<slug>/index.php`, όπου υπάρχουν έτοιμα:

| Μεταβλητή       | Περιεχόμενο                                                        |
|-----------------|--------------------------------------------------------------------|
| `$user`         | ο συνδεδεμένος χρήστης (γραμμή του `users`)                        |
| `$business`     | η επιχείρηση, με `$business['role']` = owner / manager / member    |
| `$tool`         | η γραμμή του εργαλείου στο `tools`                                 |
| `$subscription` | η ενεργή συνδρομή (πλάνο, τιμή, ανανέωση)                          |
| `$subpath`      | ό,τι ακολουθεί μετά το `/t/<slug>/`, π.χ. `codes/5`                |

Αν δεν υπάρχει ακόμα `index.php`, ο πελάτης με ενεργή συνδρομή βλέπει μια σελίδα «ετοιμάζεται».

## Κανόνες

- **Κάθε πίνακας έχει `business_id`** και κάθε ερώτημα φιλτράρει με `$business['id']`. Έτσι μια επιχείρηση δεν βλέπει ποτέ δεδομένα άλλης.
- Οι πίνακες ξεκινούν με το όνομα του εργαλείου, π.χ. `qr_codes`, `rb_reviews`.
- Χρησιμοποιούμε τα ίδια βοηθητικά με την πύλη: `q()`, `q1()`, `qall()`, `e()`, `render()`, `module_url()`, `has_role()`, `flash()`, `icon()`, `tile()`.
- Οι αλλαγές στη βάση γίνονται **μόνο** με νέο αρχείο στο `migrations/` (π.χ. `002_add_colors.sql`) και ποτέ με αλλαγή σε αρχείο που έχει ήδη τρέξει.
- Σελίδες που βλέπουν οι πελάτες των πελατών (π.χ. δημόσιο μενού, σελίδα κράτησης ραντεβού) μπαίνουν στο `modules/<slug>/public.php` και ανοίγουν στο `/p/<slug>/…` χωρίς login. Εκεί το module βρίσκει μόνο του την επιχείρηση (π.χ. από τον κωδικό στη διεύθυνση) και ελέγχει ότι η συνδρομή είναι ενεργή. Το QR Boss έχει και τη σύντομη μορφή `/q/<κωδικός>`.
- Εικόνες ανεβαίνουν με `store_image('πεδίο', '<slug>/' . $business['id'])` και εμφανίζονται με `upload_url()`.
- Σελίδες μέσα στην πύλη: `module_render('<slug>', 'προβολή', [...])` με προβολές στο `modules/<slug>/views/`.

Πλήρες παράδειγμα: `modules/qr-boss/`.

## Ελάχιστο παράδειγμα

```php
<?php
// modules/qr-boss/index.php
$codes = qall('SELECT * FROM qr_codes WHERE business_id = ? ORDER BY id DESC', [$business['id']]);

if ($subpath === '' ) {
    module_render('qr-boss', 'list', ['codes' => $codes], ['title' => 'QR Boss']);
}
not_found();
```
